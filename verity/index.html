How the branch is chosen: the solver computes the standard base passing plan for the initial shape pattern, then checks whether the distributor's own sends and the rejoiner's forwarded shape(s) both touch the dissector's room. If so, Normal and Late are genuinely different (the witness marker just moves later). If only one of those ever touches the dissector's room, Normal and Late land identically—shown with a note. If neither does (the rejoiner's shapes are already the distributor's key), Late requires the distributor to send a spare shape to the dissector purely to trigger it, which the dissector then returns.
